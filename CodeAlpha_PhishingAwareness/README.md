# CodeAlpha Project 2: Phishing Awareness Training

An interactive, responsive training module for recognizing phishing and responding safely. It is a standalone static website built with HTML, CSS, and vanilla JavaScript; no build step or dependencies are required.

## Run locally

Open `index.html` in a modern browser. For a local server, run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Training content

- Phishing basics and common warning signs
- A simulated email with interactive sender, urgency, and link clues
- Smishing, vishing, and impersonation examples
- A pause, independently verify, report, and recover response plan
- A three-question quiz with feedback, score, and retry

All suspicious-message links and buttons in the training example are inert. The examples are fictional simulations, not live phishing URLs.

## Project brief

Based on Task 2 in `Cyber Security Tasks & Instructions — CodeAlpha`: teach recognition of phishing emails and fake websites, explain social engineering, provide prevention tips, and include examples and interactive quizzes.
